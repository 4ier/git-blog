# 博客批注功能方案

## 概述

为技术博客添加批注功能，允许读者选中文章内容并添加批注评论，类似飞书文档的批注体验。

## 核心需求

- 读者可以选中文章中的任意文本片段
- 对选中内容添加批注（支持 Markdown）
- 批注支持嵌套回复
- 批注在页面右侧展示，与原文关联
- 使用 GitHub 账号认证

## 技术选型

| 层面 | 选择 | 说明 |
|------|------|------|
| 存储 | Giscus (GitHub Discussions) | 单 Discussion 存储所有批注 |
| 认证 | GitHub OAuth | Giscus 内置支持 |
| 批注定位 | Quote-based | 引用原文方式，稳定可靠 |
| 前端 | 原生 JS | 不引入框架，保持轻量 |

## 交互流程

```
选中文本 → 浮出「添加批注」按钮 → 点击打开输入框 → 编写批注 → GitHub 登录 → 提交 → 右侧栏显示
```
